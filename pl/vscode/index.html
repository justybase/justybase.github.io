FAQ JustyBase Core (NetezzaSQL)

Czym jest JustyBase Core (NetezzaSQL)?

To rozszerzenie bazodanowe i SQL dla Visual Studio Code zorientowane na Netezza, z wbudowanym sterownikiem i wspólną przestrzenią roboczą dla połączeń, schematów, zapytań i wyników.

Czy paczka Netezza jest wymagana?

Tak. Paczka Netezza zapewnia wspólną przestrzeń roboczą JustyBase i jest wymagana przed instalacją opcjonalnych paczek baz danych.

Które bazy danych mają opcjonalne paczki?

Opcjonalne paczki są dostępne dla PostgreSQL, MySQL, Oracle, Microsoft SQL Server, Db2, DuckDB, Snowflake i Vertica. Obsługa SQLite jest wbudowana.
