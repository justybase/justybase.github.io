Skupione narzędzia na całej drodze od pliku SQL do wyniku z bazy, z lokalną pomocą, gdy jej potrzebujesz.

Edytor SQL

Podświetlanie składni, zwijanie kodu, autouzupełnianie, Quick Open i pisanie zorientowane na Netezza w codziennej pracy z zapytaniami.

FAQ JustyBase

Czym jest JustyBase?

To wieloplatformowe desktopowe IDE SQL skupione na IBM Netezza Performance Server: edycja SQL, eksploracja schematu, przepływy Git, narzędzia do danych i opcjonalna lokalna pomoc AI.

Które systemy operacyjne są obsługiwane?

Proces wydawniczy buduje paczki dla Windows x64, Linux x64 i macOS ARM64. Paczka dla macOS jest przeznaczona dla Apple Silicon.

Które bazy danych są dziś obsługiwane?

Obecnie wspierana jest Netezza. Pozostałe silniki są w architekturze wtyczek, ale repozytorium oznacza je jako „wkrótce” lub prace w toku.

Czy AI wysyła mój SQL do zdalnej usługi?

AI jest opcjonalne. Wbudowane FIM działa lokalnie; Ollama i LM Studio używają skonfigurowanych lokalnych endpointów. Zachowanie zdalnych dostawców zależy od dostawcy i kontekstu, który jawnie wyślesz.
