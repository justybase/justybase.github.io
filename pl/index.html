01 / APLIKACJE

Flagowe aplikacje.

Trzy środowiska SQL na drodze od edytora do wyniku zapytania — każde z własną stroną produktu.

01 VS CODE

JustyBase SQL Editor

Rozszerzenie SQL dla Visual Studio Code zorientowane na Netezza: wbudowany sterownik JavaScript, przeglądarka schematu, eksplorator wyników, ERD i projektant ETL, notebooki oraz asystent SQL z AI. Opcjonalne paczki dodają Db2, PostgreSQL, Snowflake, Oracle, MSSQL, MySQL i DuckDB.

02 / BIBLIOTEKI I STEROWNIKI

Zestaw narzędzi pod spodem.

Sterowniki, parsery i biblioteki formatów plików, które napędzają aplikacje — i działają także samodzielnie.

C#.NET

JustyBase.NetezzaDriver

Czysty sterownik ADO.NET w C# dla IBM Netezza — bez zależności natywnych i ODBC. API sync/async, pule połączeń, introspekcja katalogu, zgodność z AOT.

Zobacz na GitHubie
C#.NET

JustyBase.Db2

Zarządzany sterownik .NET o otwartym kodzie dla IBM Db2 działający na protokole DRDA, z obsługą ADO.NET.

Zobacz na GitHubie
TypeScriptNODE.JS

@justybase/netezza-driver

Czysty sterownik Netezza / PureData w TypeScript dla Node.js: pule połączeń, SSL i API w stylu ADO.NET (Connection / Command / Reader).

Zobacz na GitHubie
RustRUST

nz_rust

Czysty klient Rust dla IBM Netezza i PureData — klient synchroniczny, asynchroniczna fasada dla Tokio, pule, anulowanie i strumieniowanie w ograniczonej pamięci. Wersja preview.

Zobacz na GitHubie
